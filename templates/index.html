About SmartChat AI

SmartChat AI is a modern AI-powered chatbot web application developed using Python, Flask, HTML, CSS and JavaScript.

Core Technologies & Architecture:

Python Core programming language powering the backend server and ML pipelines.
Flask Lightweight and flexible web framework for REST API routing and session management.
HTML5 Semantic, accessible document structure for desktop and mobile devices.
CSS3 Custom CSS design system with CSS variables, 6 theme palettes, and glassmorphism.
JavaScript (ES6+) Client-side interactivity, asynchronous Fetch API, and Web Speech API.
AI API Engine Groq Llama 3.3 70B, Google Gemini, OpenAI GPT-4o-mini & scikit-learn Local NLP.
SQLite Lightweight, reliable relational database for user authentication and chat history.
